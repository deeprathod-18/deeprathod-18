`Python` · `JavaScript` · `RAG` · `Gemini Embeddings` · `pgvector` · `Mistral LLM` · `Supabase`

Engineered a voice-enabled AI interview platform that generates personalised interview questions from a candidate's resume and target job description, with a real-time speech pipeline (Deepgram STT + Edge TTS).

- 🧠 Implemented semantic retrieval using 1536-dimensional Gemini embeddings and pgvector similarity search for context-aware questioning — achieving **&lt;3s response latency**
- 📝 Automated answer scoring, feedback generation & final reporting via Mistral AI, cutting manual review effort by **~90%**
