*Python · JS · RAG · Gemini Embeddings · pgvector · Mistral LLM · Supabase*

Engineered a voice-enabled AI interview platform generating personalized questions from a resume and job description, using RAG and a real-time speech pipeline (Deepgram STT + Edge TTS) for natural back-and-forth interviews.

| Metric | Result |
|---|---|
| Response Latency | < 3 seconds |
| Manual Scoring Effort | ↓ ~90% |
| Embeddings | Gemini 768-dim + pgvector similarity |
| Speech Pipeline | Deepgram STT + Edge TTS |
